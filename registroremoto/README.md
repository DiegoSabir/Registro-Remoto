# Registro-Remoto


## Guia de Usuario

Al abrir la aplicación nos encontraremos un formulario en el que habrá que introducir tanto el correo como la contraseña de la cuenta de Odoo. Además tambien existe en esta ventana un boton settings donde se puede cambiar el servidor Odoo.

<image src="assets/images/Captura-gu-1.png" alt="Ventana de login">

Una vez el usuario haya escrito unas credenciales válidas se le enviará al apartado de fichaje donde habrá dos botones uno para registrar su entrada/salida en su servidor Odoo y otro para registrar dietas, que al pulsarlo lleva a una nueva ventana con un formulario.

<image src="assets/images/Captura-gu-2.png" alt="Ventana de fichaje">

En la ventana del formulario se tendra que rellenar la descripción, el coste y la cantidad de forma obligatoria para registrar la dieta, además siempre se añadira el tipo aunque por defecto sera gasto, por ultimo se puede añadir una imagen de manera opcional.

<image src="assets/images/Captura-gu-3.png" alt="Ventana de dietas">
